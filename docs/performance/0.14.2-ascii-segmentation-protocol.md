compilation and cleanup. They are not benchmark qualification. The fixed benchmark
includes fresh worker startup in each authorized native query. Investigate reducing
the initialization cost of exact ordinary segmentation for entirely ASCII text.

Use a small, separately checked automaton for entirely ASCII input. Load the full
Unicode automaton on its first actual use. Both paths must preserve every upstream
ordinary token boundary, rank, exact count, special-token-as-data rule and tokenizer
identity. Keep checked automaton loading; do not introduce unsafe deserialization,
skip validation or change regex/vocabulary/dependency versions. Unicode is retained.
No graph selection, authorization, quota, protocol, SDK or caller-text cache changes.
