The native selector now distinguishes a source-locator match from an incidental text mention.
An authorized, non-copied source matching a still-unwitnessed locator term can contribute gain
after ordinary word coverage is satisfied. Existing prepared closures and term postings are
reused; no model, query-specific answer, benchmark identifier or extra index is introduced.
The witness lookup is shared within the scoring loop. This remains a lexical heuristic, not
semantic proof. All scope, complete-dependency, exact-token and aggregate-work checks apply.

before the runtime change. Four negative controls passed on the baseline. Retain the original

cost per completely covered answerable evidence query rose from 64.0741 to 64.5714. All original

compound names and conjunction/semicolon lists. A new worker and new complete paired cohort
are required; do not overwrite or reclassify the first candidate.
