# WP00 verification

WP00 establishes build infrastructure only. Commands that depend on later product capabilities fail with an explicit owning packet instead of returning placeholder success.

## Local fast gate

```sh
cargo xtask bootstrap
cargo xtask fmt --check
cargo xtask generate --check
cargo xtask lint
cargo xtask test unit
cargo xtask docs --check
```

Bootstrap validates pinned required tools and lockfiles without installing software. Optional quality tools are reported with installation documentation; CI owns their isolated execution.

## Shared development services

`docker compose -f deploy/compose/development.yaml up -d` starts a pinned PostgreSQL service and S3-compatible object storage. Credentials are fixed local-only values and must never be reused outside the development compose network.
