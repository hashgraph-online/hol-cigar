CIGAR command-line interface

Usage: cigar [GLOBAL OPTIONS] <command> [subcommand] [resource-id]

Commands:
  cigar init
  cigar source add | list | refresh | inspect | remove
  cigar ingest
  cigar catalog query
  cigar status
  cigar context plan | compile | explain | diff | revalidate | materialize
  cigar project list | attach | detach | switch | link | unlink
  cigar focus new | switch | checkpoint | close
  cigar space fork | publish | log | conflicts
  cigar handoff create | preview | inspect | accept | revoke | merge
  cigar effect prepare | approve | dispatch | list | inspect | reconcile | compensate
  cigar replay reconstruct | run | compare | completeness
  cigar policy check | explain
  cigar backup create <archive>
  cigar backup verify <archive>
  cigar backup restore <archive> <empty-target>
  cigar migration preflight <v4-source.sqlite3> <verified-backup> <new-v5-target.sqlite3>
  cigar migration run <v4-source.sqlite3> <verified-backup> <new-v5-target.sqlite3> --yes
  cigar migration activate <v4-source.sqlite3> <verified-backup> <v5-target.sqlite3> <signed-receipt.json> <active-store.json> --yes
  cigar migration cleanup <v4-source.sqlite3> <verified-backup> <incomplete-v5-target.sqlite3> <active-store.json> --yes
  cigar compaction preview <v5-source.sqlite3> <migration-receipt.json> <new-target.sqlite3> <active-store.json> <new-preview.json> --yes
  cigar compaction execute <signed-preview.json> --yes
  cigar compaction status <active-store.json>
  cigar integrity deep <v5-database.sqlite3> [--force-full] --yes
  cigar gc plan <new-signed-plan.json> [--input <gc-policy.json>] --yes
  cigar gc run <signed-plan.json> --yes
  cigar diagnostics bundle <content-free-support.tar>
  cigar state inspect-beta <0.1.0-beta.1-state.json>
  cigar state import-beta <0.1.0-beta.1-state.json> <new-backup-directory>
  cigar state restore-beta <verified-backup-directory> <new-empty-recovery-directory>
  cigar doctor [--security] [--deep]
  cigar serve
  cigar mcp serve
  cigar plugin install claude-code
  cigar plugin uninstall claude-code
  cigar plugin doctor claude-code
  cigar release verify
  cigar completion <bash|zsh|fish>
  cigar man
  cigar help
  cigar version

Global options:
  --output <text|json>                 Select human or versioned machine output
  --deadline <Nms|Ns|Nm>              Bound the complete command (maximum 5m)
  --config <path>                     Add an explicit CLI configuration layer
  --target <embedded|local|remote>    Select the execution target explicitly
  --embedded | --local | --remote URL Target shortcuts
  --endpoint <URL>                    Override the selected target endpoint
  --authorization-file <path>         Read authorization without exposing it in argv
  --input <path>                      Strict JSON operation request document
  --idempotency-key <key>             Reuse an exact mutation reservation
  --expected-revision <revision>      Bind an optimistic mutation
  --page-cursor <cursor>              Continue a bounded listing
  --page-size <1..1000>               Bound one page
  --dry-run                           Validate and authorize without committing
  --yes                               Confirm a reviewed state change
  --confirm                           Alias of --yes
  --non-interactive                   Disable all prompts
  --quiet                             Disable progress
  --color <auto|always|never>         Control optional color
  --unicode <auto|always|never>       Control status glyphs
  --width <20..1000>                  Bound human layout
  --explain-config                    Print effective values and their sources
  --security                          Run local security diagnostics
  --deep                              Verify hashes, journals, and projections
  --force-full                        Ignore a signed prefix and verify all retained v5 history
  --help                              Show this help (alias: -h)
  --version                           Show build metadata (alias: -V)

Mutations require --yes unless --dry-run is used. JSON is emitted only on stdout;
progress is emitted only to an interactive stderr. Secrets are accepted only through files.
Local source/project/focus references do not rewrite the daemon's trusted production registries.
Beta-state inspection and transition receipts are content-free: they emit digests and counts, never
paths or identifiers. Import requires a verified exact-byte backup and publishes a new full-only
state directory atomically. In-place downgrade is blocked; restore writes only a distinct new empty
recovery directory.
